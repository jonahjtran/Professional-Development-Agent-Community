# Familiarity baseline

Edit this file. The learn-as-you-build skill treats anything listed under "Comfortable" as already known and skips explaining it. Anything under "Learning" or not listed gets explained. If you tell Claude you already knew something, it gets added here.

## Comfortable (skip the basics)
- Python and general scripting
- Full-stack web basics: Next.js / React, building a CRM-style app end to end
- Calling LLM APIs and building RAG systems
- Building an MCP (Model Context Protocol) server that connects an LLM to external data
- Basic agentic AI concepts (tool use, agent loops)
- Core data structures and algorithms (interview-prep level)
- Git and GitHub workflows, pull requests

## Learning (explain with a walkthrough)
- Graph databases and graph query languages, beyond what fraud-detection work required
- Multi-agent orchestration patterns (handoffs, shared state, orchestrator design)
- Claude Agent SDK internals
- Cloud services and deployment (AWS Cloud Practitioner level, not hands-on depth)
- Production concerns: observability, testing strategy, CI/CD, security hardening

## Not sure (explain briefly, ask if it was new)
- Anything not listed above
